# Platforms & compatibility

`ui-ux-magec install-integrations` writes project-scoped files. `setup.command` offers the user-scoped
equivalents and asks before writing each one. Generated files carry a `generated by ui-ux-magec` marker. A
file without the marker is never overwritten unless you pass `--force`.

| Capability | Claude Code | OpenAI Codex | OpenCode | CLI (autonomous) |
|---|---|---|---|---|
| MCP server registration | `.mcp.json` (project) / `claude mcp add --scope user` | `~/.codex/config.toml` `[mcp_servers."ui-ux-magec"]` block | `opencode.json` `mcp` (project) / `~/.config/opencode/opencode.json` | n/a (in-process) |
| Orchestrator entry point | `.claude/skills/ui-ux-magec/SKILL.md` | `AGENTS.md` section (project) / `~/.codex/AGENTS.md` | primary agent `magec-master-orchestrator` | `ui-ux-magec start --autonomous` |
| Specialists | Subagents `.claude/agents/magec-*.md` | Role switching via `magec_agent_brief` and `as_agent` (no native subagents) | Subagents `.opencode/agent/magec-*.md` | One Claude API loop per task |
| Per-agent tool restriction | `tools:` list (only permitted `mcp__ui-ux-magec__*` tools plus read-only host tools) | Enforced server-side only (permissions checked per `as_agent`) | `tools:` map (`ui-ux-magec_*: false` plus allowed tools) | Tool list filtered per agent |
| Server-side permission enforcement | ✓ | ✓ | ✓ | ✓ |
| Verified in this repo | Generated files and MCP protocol tested; **not run inside Claude Code here** | Generated config tested; **not run inside Codex here** | Generated files tested; **not run inside OpenCode here** | Loop tested with scripted (mock) agents; **live Claude API not exercised** (no key) |

Notes:

- `as_agent` defaults to `master-orchestrator`. Subagent definitions tell each specialist to pass its own ID.
  A host could omit it, but it cannot gain permissions it doesn't have: the orchestrator cannot write to
  Figma.
- OpenCode's frontmatter `tools` glob semantics and Codex's `startup_timeout_sec`/`tool_timeout_sec` keys
  follow those tools' documented formats. Re-check them if either tool changes its config schema.
